# 📖 Dashboard - Admin<a name="about-project"></a>

> Dashboard - Admin is a responsive design of an admin panel that shows the various menus of an app on a side menu. It also has a top nav menu that also displays some menu items. The dashboard includes display of analytics using graphs.
>
> Dashboard - Admin is a responsive design of an admin panel that shows the various menus of an app on a side menu. It also has a top nav menu that also displays some menu items.

## 🛠 Built With <a name="built-with"></a>
1. React
2. Material UI
3. Recharts
4. SASS

<!-- Features -->

### Key Features <a name="key-features"></a>

> - Display Analytics with graph
> - Display side menu and top menu items
> - Manage Users
> - Manage Products
> - Switch between Light and Dark modes
